# Every other file, read

The reading log's second half. `scripts/COMMENTS-READ.md` holds the files
`scripts/comment-truth.js` checks; this holds every other file of the reading
map (`scripts/reading-map.cjs`): the SQL, the data and settings files, the
native code, the email templates, the website host's preview-card endpoints.

Rows are written only by `scripts/ledger-write.cjs`: a read from a coverage
record taken from the reader's own work log, or "—" for a file never read.
"Read" is the day the reading ended; the record it names holds the commit read.
`scripts/__tests__/readingLog.test.ts` holds this file to the map.
